# PORTIFÓLIO - DOMINOO


## Objetivo

A crição desse site estilo portifólio é práticar os  conhecimentos adquiridos na minha faculdade até o presente momento. 

## Propósta do site
A idéia é criar um site real, a administradora do site é minha irmã a qual possui seu hobby em desenho digital e manual. O objetivo é a criação de um portifólio de seus desenhos de uma maneira diferenciada com um estilo todo focado na personalidade de seus desenhos.
